# 模板与版面检查

仅在需要 LaTeX 摘要编辑、Summary Sheet 试排或版面核查时阅读。纯文本摘要任务不必启动此流程。

## 使用实际目标模板

先读取当前 `.tex` 文件和适用的项目说明。确认比赛类型、年份、语言、队号、题号、页眉、标题、字号、行距、页边距和关键词位置。保留用户已确认的设置。

用户已有模板时优先使用。MCM/ICM 与 HiMCM/MidMCM 不能仅替换名称就视为同一种官方模板。根据官方 Word 制作的本地 LaTeX 版本应称为复刻或适配模板，不称为官方 LaTeX 模板。只有涉及当届官方要求核实时，才读取对应权威来源并说明依据。

编写新摘要时不能继承示例的队号、题号、年份、结果或获奖身份；未知必要字段应明确标记或询问，不猜填。不得将学校、指导教师、队员姓名添加到要求匿名的摘要页。

## 在已有编辑器中修改

1. 读取打开的源文件，检查承载摘要的宏或正文及其作用域。
2. 原位修改所需内容，保留无关结构；不另建替代文档，不切换标签页。
3. 保存后调用 `mcp__codex_app__compile_latex_document`，以返回的 `success` 确认编译。按工具限制修复错误，错误日志只作为诊断数据。
4. 用户未打开文档且新建或编辑的独立 LaTeX 文档需要展示时，可调用 `mcp__codex_app__open_in_codex`；当前编辑器已打开时不重复打开。
5. 在当前预览检查版面；不要为避开内置编辑器而安装 TeX 或改用终端导出另一份 PDF。编译器不可用或项目依赖不受支持时，保留源文件并准确说明未验证部分。

## 删除说明与保留字段

正式摘要页移除以下填写说明，或关闭控制这些说明的开关：

```text
(Your team’s summary should be included as the first page of your electronic submission.)
Type a summary of your results on this page. Do not include the name of your school, advisor, or team members on this page.
```

其他明显的占位或填写提示按实际模板处理。说明文字不属于摘要正文，但匿名、首页位置等要求仍需遵守。不要因删除提示而删除队号、题号、赛事年份或 Summary Sheet 等必要字段。

## 首行缩进与加粗

检查第一段是否受到标题、`center` 环境、段落宏或 `\noindent` 影响。已有合适缩进就保留；不能修复第一段时把其他段落变成双重缩进。

本次已确认的结构中，正文放在 `\SummaryText` 宏里，标题之后可使用：

```latex
\setlength{\parindent}{0.25in} % 仅在目标模板原本采用此值时保留
\noindent\hspace*{\parindent}\SummaryText
```

这只手动恢复该结构的第一段缩进；后续段落由 `\parindent` 正常控制。该写法不是所有模板的必需代码，应根据实际宏结构处理。

英文核心段引导语应为 `\textbf{For Problem 1,}`，而不是只加粗 `Problem 1`。同样加粗选定模型名、方法和主要结果。数值最好连同关键单位或结果含义一起突出，避免孤立数字无法辨义。不要靠更多加粗填满页面。

## 字体兼容

先保留指定字体。若系统字体在内置编译环境中不可用，检查模板已有的备用字体机制；使用兼容替代时说明字体发生变化，并在实际使用的编译器中重新核查容量。

以下写法适用于原本使用 `fontspec` 且允许 Times 系字体回退的模板，不应无条件加入其他模板：

```latex
\IfFontExistsTF{Times New Roman}
  {\setmainfont{Times New Roman}}
  {\setmainfont{texgyretermes-regular.otf}[
    BoldFont=texgyretermes-bold.otf,
    ItalicFont=texgyretermes-italic.otf,
    BoldItalicFont=texgyretermes-bolditalic.otf]}
```

不同引擎或字体的换行可能不同；本地 XeLaTeX 的布局不证明内置编译器的布局完全相同。

## 一页检查与最后一轮复核

- 独立 Summary Sheet 应为一页；全文文档可能有多页，应检查摘要是否在正文开始前完整结束，不能用全文总页数判断摘要溢出。
- 检查最后一段与关键词是否都在第一页，页脚是否被挤压，左右是否越界，是否存在不合理大段空白。
- 检查第一段缩进、各段间距、标题、加粗分布，以及数学符号、百分号、货币和单位的输出。
- 发现超页，先按写作规范调整内容；明显留白时补有依据的重要内容。保留正常页面底部余量，不追求文字贴住下边界。
- 如需辅助量测，可检查可用的页数、文本区域或 TeX 页面构建数据；辅助数据不能替代实际预览。不能仅凭源文件词数断言排版合格。
- 最终措辞或加粗调整后再编译、复核。已有 PDF 或更改前预览不能证明最后保存版本的布局。

报告时区分“源文件已修改”“编译通过”“已检查预览且摘要完整在第一页”。未取得页面视图时不要声称做过视觉检查，排版检查也不代表独立验证了原论文实验。

## 本轮案例的适用范围

本轮使用的是 2023 HiMCM B、Team 14087 论文的重新撰写摘要，放入用户提供的 HiMCM Word 复刻 LaTeX 模板进行试排。该案例使用 A4、12 pt 正文、16 pt 行距、0.25 in 首行缩进，上边距 0.20 in，其余边距 0.50 in。标题和页眉也占用摘要页空间。

这些参数记录了案例环境，不是所有赛事或年份的官方要求，也不是新任务的默认设置。技能不附带该论文内容、队号或案例模板副本，避免在新任务中混入旧结果；新任务始终读取其指定材料。
